The Seventh Cycle on One Page

Every eight years the state assigns the region a housing number — last time, 171,685 homes — and SANDAG divides it among 19 cities. The total never changes, only the split. Fair-housing law requires that homes for lower-income families be steered toward neighborhoods with good schools and jobs. We built and tested an allocation system that anyone can check, using only public data, to prepare for the next round.

Three things the work found

1

The last plan's math could not be checked — now it can be. We rebuilt the 2020 allocation and matched it to within two homes per line, which required reconstructing a calculation no published document describes. The one error ever found in it (Navy jobs in the wrong cities) took a formal appeal to surface; an open system catches that class of error before a draft goes out.

2

Fair housing moved from the percentages to the totals. The 2019 methodology applied it to each city's income mix, and the state approved. The state now expects it to shape how many homes each city gets. Under any lawful next-cycle formula, high-opportunity coastal cities rise — the ranges below — regardless of what else the methodology weighs.

3

Safety data works — as placement, not as reduction. Our evacuation model, tested by replaying every major fire since 2000, independently identified Wildcat Canyon Road — where the Cedar Fire's victims died. Used as a placement factor it moves roughly 7,300 homes onto safer ground at an identical fair-housing score. Used to cut a fire-exposed city's total, it would push homes into the region's struggling neighborhoods — so the software refuses to compute that, for anyone.

Four decisions ahead of the late-2027 state deadline

  1. Talk to state housing staff informally — test the placement approach and the "more-affordable-coastal / more-market-rate-inland" option ahead of formal submission.
  2. Build the open jobs count — the last one was closed and contained the Navy error; several design options depend on a trustworthy replacement.
  3. Calibrate the evacuation model against real traffic counts and summer visitor loads — predictions logged before results, misses published.
  4. Set placeholder targets for the six income levels the next cycle requires, so trial runs can start before the state's number lands.

Questions worth asking us
