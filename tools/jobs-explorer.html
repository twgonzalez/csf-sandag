Check Your City's Jobs Number

Jobs helped decide the last housing allocation, and several cities doubt the jobs credited to them. This page shows, for each of the 19 jurisdictions, where an open jobs count comes from — the census-visible jobs, the military layer, the headquarters corrections — next to the 2019 figures, down to the neighborhood. Every number is precomputed by a public pipeline; this page only displays it.

An independent analysis, built entirely on public data so every claim can be checked. It offers no recommendations — it exists to raise better questions before the seventh cycle's decisions arrive. Think a number is wrong? Say so — that is what open methodology is for.
