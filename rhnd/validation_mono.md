# Validation: reproducing HCD's published 7th-cycle determinations

Regenerated by `rhnd/run.py validate`. Letter values from the Mono
County final determination (2026-01-23, corrected; data/raw/hcd_rhnd_mono_7th/) and the HCAOG board staff report of
2025-09-18 quoting HCD's Humboldt determination of 2025-07-15
(data/raw/hcaog_rhnd_7th/).

Two runs per region: **adjustments** injects the letter's own
growth block (lines 1-4, 14), isolating every adjustment line we
compute from public data; **full pipeline** also computes the
growth block from public DOF files (P-2A/P-4). HCD's growth block
comes from DOF Demographic Research Unit extrapolations that are
not published ('detailed background data available upon request'),
so the full-pipeline residual is dominated by that block.

## Known irreducible differences

- **Line 8 (overlap), Mono**: DOF tabulates the overlap for Mono
  County alone; public PUMS places Mono inside the seven-county
  Eastern Sierra PUMA 00300, so the public rate (1.29%) is a PUMA
  rate. San Diego County has county-exact PUMAs, so the SANDAG run
  does not inherit this limitation.
- **Line 5b, Mono (+4)**: the letter applies healthy vacancy rates
  to 'projected households', but Mono's projected household growth
  over the projection period is negative in every public DOF
  series; no public reading reproduces +4. The line is computed as
  healthy rates x positive projected household growth (0 for Mono).
- **Line 12, Humboldt (+769)**: the letter names the Humboldt
  Housing & Homelessness Coalition's own 2024 Point-in-Time count as
  the source; the HUD workbook's CA-522 count (1,573) x DOF
  formation rate gives 703. The 66-unit difference is the CoC's
  local count vs HUD's published one. San Diego's CoC count comes
  straight from the HUD workbook, so SANDAG does not inherit this.
- **Lines 6/7, two formulas**: both letters use the same >=30%
  cost-burden and >1.00 persons/room rates (computed-denominator;
  our values match both letters' printed rates exactly), but the
  Humboldt letter computes the units needed to DILUTE the region to
  the US rate - (burdened - US_rate x households)/(1 + US_rate),
  reproducing +349 exactly and +3,639 within 1 - while the later,
  corrected Mono letter takes the plain rate difference times
  households (computed 154/444 vs letter 155/447). Both formulas
  are implemented (cb_variant); the SANDAG run reports both.
- **Growth block (lines 1-4, 14)**: HCD/DOF extrapolations are
  unpublished. Public P-2A (Wayback snapshot of 2025-11-19, the
  file HCD had during consultation) reproduces Mono's population
  line within 31 persons (0.25%); the P-4 household lines differ
  by 1-4% and the start/end difference (the growth component of
  need) differs by ~70 units for Mono and ~370 for Humboldt.
